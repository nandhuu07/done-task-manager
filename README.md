# DONE. – Personal Task Manager

DONE is a simple and minimal personal task-management web application.

It allows users to create, organize, complete, filter and delete everyday tasks without creating an account.

## Features

- Add new tasks
- Set task priorities (Low, Medium, High)
- Mark tasks as completed
- Reactivate completed tasks
- Delete tasks
- Filter tasks (All, Active, Completed)
- Display remaining task count
- Save tasks using browser LocalStorage
- Responsive design for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- Git
- GitHub

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Start managing your tasks!

## Storage

DONE uses browser LocalStorage to save tasks locally.

No user accounts, cloud storage or external database are required.
